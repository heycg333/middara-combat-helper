# Middara Combat Helper V3.0C

This folder is the GitHub Pages root package for V3.0C Attack Resolver.

Upload the extracted contents to the root of the GitHub Pages repository, replacing the existing files:

- index.html
- manifest.webmanifest
- service-worker.js
- CURRENT_VERSION.txt
- .nojekyll
- icons/

After GitHub Pages deploys, open the hosted app and use Data -> Update app cache, then reload/reopen the Home Screen app.
