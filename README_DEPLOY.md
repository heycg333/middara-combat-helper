# Middara Combat Helper V2.2J Hosted / PWA Package

This folder is the GitHub Pages root for Middara Combat Helper V2.2J.

## Upload

Upload these extracted files to the root of your GitHub repository:

- `index.html`
- `manifest.webmanifest`
- `service-worker.js`
- `.nojekyll`
- `CURRENT_VERSION.txt`
- `README_DEPLOY.md`
- `icons/`

Do not upload the ZIP file itself as the app.

## After deployment

1. Wait for GitHub Pages to finish publishing.
2. Open the hosted app on the tablet.
3. Go to **Data > V2.2J hosted / installable web app**.
4. Tap **Update app cache**.
5. Reload or reopen the Home Screen app.
6. Confirm the app shows V2.2J.

## Save-state reminder

The app is local-first. Saves are stored in this browser for this hosted URL. Multiple devices do not sync live. Export a full snapshot before updating the app or changing devices/URLs.

## V2.2J notes

V2.2J is a live-play readiness pass. It keeps the V2.2H tablet flow and adds:

- in-app live-play guide near the Table Session Hub
- explicit before/during/after encounter checklist
- table workflow self-test
- clearer hosted/PWA/save-state status
- updated headings that remove confusing legacy section numbers
- updated external reference guide files

Board legality, SOI, adjacency, movement, line of sight, and hidden text remain manual.

## Icon

This package uses the supplied Remi square artwork for the Home Screen / PWA icon files. If the old icon persists on iOS, remove the Home Screen shortcut, open the site in Safari, update the app cache, then add it to the Home Screen again.


## V2.2J notes

- The Mobile / Tablet Combat Flow is promoted to the first Play panel.
- The Table Session Hub and Live-Play Guide are collapsed below the four-step flow so Actor / Target / Action / Resolve stays visible.
- Use the small jump buttons above the flow to move directly to Actor, Target drawer, Action, or Resolve / Apply.
